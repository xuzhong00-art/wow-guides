# ADR 0001: 导入码为唯一真源（Import Code as Source of Truth）

日期：2026-08-25
状态：已采纳

## 背景

专精页的循环优先级抓取自 Wowhead/Archon 的通用攻略，这些攻略覆盖多种天赋构建；而页面顶部的天赋导入码只是其中一种具体构建。两者没有对齐校验，导致循环列表中出现当前构建根本没点的技能（2026-08 由使用者在实际使用中发现）。

## 决策

1. **页面顶部的天赋导入码是该专精页的唯一真源（"宪法"）**。循环优先级、键位表、宏，全部以导入码构建为准进行校验。
2. **游戏内改天赋的纪律**：先更新页面导入码，页面其余内容随之对齐。
3. **循环中需额外天赋的技能保留但标注**（"⚪需天赋：X"），不直接删除——保住"改一个天赋点不必重查攻略"的能力。
4. **校验机制（半自动）**：刷新管线抓取构建页时，将天赋列表一并存入页面（隐藏注释或 JSON），刷新时用它交叉核对循环并打标注；下次刷新复用。

## 后果

- 存量页面的对齐修复并入 S2 数据刷新执行（同批完成：数据刷新 + 循环对齐标注 + 文字精简为速查卡风格）。
- 拒绝的替代方案：全自动导入码解析器（维护 Blizzard 天赋字符串编码格式，成本远超收益）；每次人工核对（重复劳动且易漏）。
